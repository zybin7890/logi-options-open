# 完全替代 Options+：Windows 验收表

目标是 MX Master 3S 在没有官方 Options+ 的机器上独立、长期可用。不能用编译、模拟输入或旧版本的反馈替代当前版本实测。登录、广告、营销和遥测明确排除；Linux 暂停，先完成 Windows。

状态必须分为：未实现、实现但未实测、实体通过、稳定性通过。下面记录本轮候选及本机部署结果；实体证据见 [实测记录](LIVE-VALIDATION.md)，不是跨设备稳定性保证。

| 功能 | 当前候选状态 | 完成所需证据 |
|---|---|---|
| 侧键、中键、顶部按钮 | 侧键实体通过；中键/顶部按钮尚未独立验收 | 浏览器前进后退、中键、滚轮模式与自定义动作逐项成功 |
| 主轮与拇指轮 | 本机当前映射经用户确认通过；全模式和极端速度未验收 | 纵/横滚动、方向、速度、音量及标签页映射；慢速与快速滚动无丢失或突跳 |
| DPI、SmartShift、高分辨率和滚轮模式 | 真实往返、读回、保存及恢复通过；GUI 加载 5000 通过 | 长期运行与不同连接状态下仍一致 |
| DPI 重启保留 | 进程重启 5050→保存的5000通过；整机重启未验收 | 登录后不打开 GUI，硬件读回等于保存值；不允许只比较配置文件 |
| 普通点击、四向与 Pan 手势 | 用户确认原有任务视图/桌面手势正常；Pan、完整四向矩阵未验收 | 真鼠标下按住移动、释放、切窗及取消行为；没有误点击或卡键 |
| 连续媒体手势 | 代码、隔离测试、实际预设 UI 及本机用户反馈通过 | 原版手感校准、长时间重复动作与跨应用行为 |
| 原版其它连续手势及应用导航 | 部分未实现 | 连续轴、方向锁定、暂停/重复、Alt 生命周期的原版语义与真实输出 |
| 应用专属配置 | 实现；当前候选未实测 | 全局与应用配置切换、进程路径/名称优先级、切窗不误发旧动作 |
| Smart Actions | 部分实现 | 完整创建、触发、等待、文本、应用动作、失败反馈、取消与清理；补齐缺失动作 |
| Actions Ring | 部分实现 | 真鼠标选项、取消、子菜单、焦点恢复、图标与中文显示一致 |
| CLI / API / MCP | 已有代码；新命令返回值与接口仍需端到端核对 | 设置返回真实后台确认；版本一致；未确认不能报成功 |
| 登录自动接管 | 本机启动项已配置、相同启动脚本已实测；真实登录未验收 | 重启/注销后无需打开 GUI；仅一套后台；实际按钮和 DPI 正常 |
| 休眠、唤醒、断连、接收器拔插 | 隔离恢复测试存在；实体待测 | 重复循环恢复映射与参数；失联时保留标准输入；无重复事件 |
| 后台退出、崩溃与输入恢复 | 有恢复路径；故障恢复未全部验收 | 不留下失效按键/滚轮或按住的修饰键；恢复无需官方软件 |
| 低内存和延迟 | 短时约8.50–8.52 MiB；约30秒句柄不增长；最长设置请求约999毫秒 | 空闲和持续使用的工作集/私有内存、CPU、句柄、延迟及增长趋势 |
| 旧版界面复用与外观 | Win32 旧版保留；预设交互和真实 DPI 标签/编辑框通过 | 各页面逐项对照，缩放/小屏无错位裁切，实际动效和响应流畅 |
| Easy-Switch 与跨主机状态 | 部分实现；多机未实测 | 真实第二主机接管、返回和配置恢复 |
| Flow | 未实现 | 跨机发现、布局、边缘切换、剪贴板与键盘跟随 |
| 配对、固件更新、官方插件功能 | 未实现或不完整 | 对应设备协议、完整实现及适当环境验证 |

只有所需功能逐项闭合且重复运行没有复现输入失效，才能称为可完全替代。未有证据的项目不填“通过”，不发布稳定版；硬件相关缺项继续保留，不把它们从目标中删去。
